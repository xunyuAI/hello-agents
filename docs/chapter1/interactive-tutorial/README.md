## 如何本地打开

1. 用 Finder 进入本目录，双击 `index.html`（多数浏览器可直接打开）。
2. 或在终端执行：

```bash
open "/Users/mima0000/Desktop/ai/project/hello-agents/docs/chapter1/interactive-tutorial/index.html"
```

3. 若侧边配图未显示，确认同级 `assets/` 目录存在；部分示意图会回退到 GitHub raw 链接（需联网）。

## 操作提示

- 左侧目录跳转；顶部「上一页 / 下一页」
- 键盘 `←` `→`（或 PageUp / PageDown）翻页
- 可翻转概念卡、闪卡、选择题请点击交互
- 手机：点「目录」打开侧栏
