# 第五章 · 基于低代码平台的智能体搭建 · 互动教程

面向零基础/新手的浏览器互动学习页，覆盖 Hello-Agents 第五章全部知识点（约 **100+** 详解页，非整章提纲）。与第 1–4 章同属「工业蓝图实验室」产品线（Lab 05 薄荷绿 / 青柠信号色）。

## 如何本地打开

1. 用 Finder 进入本目录，双击 `index.html`（多数浏览器可直接打开）。
2. 或在终端执行：

```bash
open "/Users/mima0000/Desktop/ai/project/hello-agents/docs/chapter5/interactive-tutorial/index.html"
```

3. 原书配图（图 5.1–5.50、表 5.1）通过 GitHub raw 链接加载（需联网）；离线时会自动降级为「步骤文字卡」。封面示意图在本地 `assets/ch5_cover.svg`。

## 操作提示

- 左侧目录跳转；顶部「上一页 / 下一页」
- 键盘 `←` `→`（或 PageUp / PageDown）翻页
- 可翻转概念卡、展开卡片、闪卡、选择题、搭建流程步进请点击交互
- 手机：点「目录」打开侧栏
