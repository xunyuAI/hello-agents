# 第二章 · 智能体发展史 · 互动教程

面向零基础/新手的浏览器互动学习页，覆盖 Hello-Agents 第二章全部知识点。与第一章同属「工业蓝图实验室」产品线（Lab 02 地层色号微调）。

**本版为扩写精读版**：页数相对初版约增至 **3 倍**，按原书节级结构拆成独立详解页（含概念、对照、流程步进、代码走读、闪卡与自测），禁止只剩提纲。

## 如何本地打开

1. 用 Finder 进入本目录，双击 `index.html`（多数浏览器可直接打开）。
2. 或在终端执行：

```bash
open "/Users/mima0000/Desktop/ai/project/hello-agents/docs/chapter2/interactive-tutorial/index.html"
```

3. 原书配图通过 GitHub raw 链接加载（需联网）；封面地层图在本地 `assets/ch2_cover.svg`。

## 操作提示

- 左侧目录跳转；顶部「上一页 / 下一页」
- 键盘 `←` `→`（或 PageUp / PageDown）翻页
- 可翻转概念卡、闪卡、选择题、流程步进请点击交互
- 手机：点「目录」打开侧栏

## 与第一章的关系

第一章互动教程位于 `docs/chapter1/interactive-tutorial/`（初识智能体）；本章接续其视觉语言与交互模式，主题转向发展史与范式演进。两章可独立打开，按课程顺序学习即可。
