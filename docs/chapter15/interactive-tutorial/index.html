为什么要构建 AI 小镇

15.1.1 · 从对话树到「活着的」NPC

传统 NPC

  • 固定台词 / 对话树
  • 编剧写死分支
  • 可控，但难有生命力

AI NPC（本章）

  • 自然语言任意聊
  • 记得互动与关系
  • 性格、职业、说话风格独立

像《模拟人生》里有个性的邻居，但大脑换成了 LLM + 记忆 + 好感度。

应用想象（教育 / 办公室 / 陪伴）
  • 教育：历史人物、科学家互动教学
  • 虚拟办公室：同事 / 导师答疑
  • 陪伴与心理健康场景（需谨慎合规）
  • 给传统游戏直接加 AI NPC

1. 赛博小镇采用的总体架构是？

基于 HelloAgents 的 SimpleAgent

15.2.1 · 每 NPC 一个大脑

流程：定义 ID/名/职业/性格 → 拼系统提示词 → HelloAgentsLLM + MemoryManager → SimpleAgent。

def create_npc_agent(npc_id, name, role, personality): system_prompt = f"""你是{name},一位{role}。 你的性格特点:{personality} 你在Datawhale办公室工作...""" llm = HelloAgentsLLM() memory_manager = MemoryManager( working_memory=WorkingMemory(capacity=10, ttl_minutes=120), episodic_memory=EpisodicMemory( db_path=f"memory_data/{npc_id}_episodic.db", collection_name=f"{npc_id}_memories")) return SimpleAgent(name=name, llm=llm, system_prompt=system_prompt, memory_manager=memory_manager)

好感度等级划分

15.3.1 · 0–100 分五档

图 15.8 好感度等级 · 离线要点
  • 陌生→熟悉→友好→亲密→挚友

图 15.8 好感度等级

等级分数行为倾向
陌生0–20礼貌疏远、回复短
熟悉21–40自然交流、偶提工作
友好41–60更详细、会主动问你
亲密61–80私人话题、热情建议
挚友81–100无话不谈、分享感受

玩法钩子：高好感再解锁特殊情报 / 任务（扩展方向）。

好感度计算逻辑

15.3.2 · LLM 判态度，不是死加分

图 15.9 计算流程 · 离线要点
  • 对话 → 情感分析 → Δ分 → clamp 0–100 → 更新等级

图 15.9 计算流程

# 友好 +5 · 中立 +2 · 不友好 -3（再 clamp 到 [-3,5]） score_change = analyze_sentiment(player_message, npc_reply) new_score = max(0, min(100, current + score_change)) level = get_affinity_level(new_score)
解析失败默认 +2（中立），避免一次坏响应毁掉关系曲线。

好感度如何改说话方式

15.3.3 · 动态拼接系统提示词

affinity_prompts = { "陌生": "保持礼貌但不要过于热情。回复简短专业。", "熟悉": "可以进行正常的交流。回复自然友好。", "友好": "愿意分享更多信息。回复详细热情。", "亲密": "可以分享私人话题。回复充满关心。", "挚友": "无话不谈。回复亲切真诚。" } system_prompt = f"""你是{name}... 当前与玩家的关系:{affinity_level} {affinity_prompts[affinity_level]} ..."""

分数是「背后账本」；玩家感到的是语气与信息密度在变。

思考与展望

15.7.3 · 潜力与三座山

成本

每句对话打 LLM，MMO 级会很贵 → 批量/缓存/本地小模型。

延迟

推理+网络可能数秒 → 打字机动画、预生成、边缘推理。

可控

生成内容需 Prompt + 过滤护栏。

趋势：更快更便宜的 LLM、端侧小模型，让「真 NPC」从 Demo 走向产品。
