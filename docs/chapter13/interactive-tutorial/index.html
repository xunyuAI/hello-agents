13.1.1

传统规划的三大痛点

信息分散

  • 景点 / 天气 / 酒店分属不同网站
  • 手动切换、复制粘贴整合

缺少个性化

  • 通用攻略难贴合偏好
  • 预算、时间、口味难兼顾

难以调整

  • 改一处牵动顺序与预算
  • 常需整份重做
对系统说「北京 3 天，历史文化，预算中等」→ 自动出日程、地图、预算，且可局部编辑。

本章目标：把 AI 做成真有用的应用——多 Agent、全栈 Web、可交付工程。

13.2.1

数据要过「七道关」

前端表单 → HTTP → Python 对象 → 外部 API → 再变回 Python → HTTP → TS 对象 → 页面。

外部 API 字段五花八门：lng / lon / longitude。没有统一模型，每一步都可能静默出错。

如何表示并可靠传递「旅行计划」？答案：契约化数据模型。

13.2.2

原型够用，工程不够

dict 痛点

  • 字段名不统一
  • 类型错误迟到运行时
  • 加字段要改多处

Pydantic 收益

  • 类定义即契约
  • 创建即校验
  • IDE 补全 + 序列化
class Location(BaseModel): longitude: float = Field(..., description="经度") latitude: float = Field(..., description="纬度") class Attraction(BaseModel): name: str location: Location ticket_price: int = 0

13.2.3

Field · 嵌套 · 验证器

  • ... 必填；Optional / 默认值可选
  • ge/le/gt 范围约束
  • 嵌套：DayPlan.attractions: List[Attraction]
  • @field_validator(..., mode='before')：把 "16°C" 变成 16
@field_validator('temperature', mode='before') def parse_temperature(cls, v): if isinstance(v, str): return int(v.replace('°C','').replace('℃','').strip()) return v
记住：脏数据在边界清洗一次，业务代码就能当「干净数字」用。

13.2.4

Location → … → TripPlan

Location（经纬度 + 范围校验）
Attraction / Meal / Hotel / Budget / WeatherInfo
DayPlan（单日：景点列表 + 餐 + 酒店）
TripPlan（城市、日期、days、天气、建议、预算）
WeatherInfo 为何特殊？
高德温度常带单位字符串；用 before 验证器统一成 int，并容错返回 0。
default_factory=list
可变默认值不要写 = []，用 default_factory=list 避免共享同一列表。

13.3.1

单 Agent 的三堵墙

工具调用限制

SimpleAgent 每轮一工具，中间结果要手传。

时间成本

ReactAgent 多轮串行 LLM，10–30s 级等待。

提示词膨胀

一坨大 Prompt：难维护、易混、难定位故障。

旅行社：景点顾问 + 酒店顾问 + 行程规划师分工，比一个人包办更稳。

13.4.1

直接调 API 的四个问题

  1. Agent 无法自主调用——绕过 TOOL_CALL 协议就退化成硬编码函数。
  2. 参数爆炸——POI 十几个参数塞进 Prompt 不现实。
  3. 响应难解析——复杂 JSON 与格式变更要到处改。
  4. 工具管理乱——十几个 API 各自手写注册。
用 MCP：标准化工具发现与调用；HelloAgents 的 MCPTool 对接服务器。

13.4.3

三 Agent 共用一个进程

各建实例

  • 三进程
  • 易撞速率限制
  • 内存/CPU 浪费

共享实例

  • 单进程
  • 统一限流入口
  • 资源可控

在 TripPlannerAgent.__init__ 创建一次 self.mcp_tool，再 add_tool 给景点/天气/酒店三个 Agent。

13.4.4

不必事事都做成 Tool

景点配图用 UnsplashService 在 API 路由里补 image_url——无需 Agent 决策。

for day in trip_plan.days: for attraction in day.attractions: if not attraction.image_url: attraction.image_url = unsplash_service.get_photo_url( f"{attraction.name} {trip_plan.city}" )
判断标准：需要智能取舍 → Tool/MCP；固定后处理 → 服务层直调。

13.5.3

Axios 实例与超时

const api = axios.create({ baseURL: 'http://localhost:8000/api', timeout: 120000, // 多 Agent 可能 10–30s }) export const generateTripPlan = async (request: TripPlanRequest): Promise<TripPlan> => { const response = await api.post<TripPlan>('/trip/plan', request) return response.data }

拦截器做统一日志/错误处理。超时设 2 分钟，避免误杀长任务。
